  再起動アンチKFM
                              author:Halkaze

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

このキャラクターはあらゆる再起動を阻止するためのテストキャラクターです。

「起動されるのがMUGENであるか」の判定自体は簡単なものなので、その隙
を突破される可能性はありますが、判定に引っかかるMUGENを起動するのであれば
ほぼ確実に捕捉し、阻止することができるはずです。

使用したDLLやEXEのソースコードも、GPLv3ライセンスのもと公開し、同梱して
いますので、製作者各位は参考にどうぞ。


・不具合報告などはこちらまでどうぞ
    ブログ ：https://halkaze.fc2.net/
    Twitter：@halkazeMUGEN1

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

＊注意＊

・このキャラクターの参加しない試合で起こる再起動も阻止します。

・CMDOFを利用しているため、CMDOFを禁止するキャラの再起動や、
  そもそも選択される前に起こった再起動の阻止はできません。

・（面倒だったので）ファイル名、ファイル階層の変更には
  対応していません。正常に機能させるために、必ず
  「chars\Anti-RebootKFM\Anti-RebootKFM.def」
  となるように配置してください。

・外部からの強制終了や、例外の発生などで予期せぬ終了が起こった場合、
  MUGENが完全に停止した後にも影響が残る場合があります。
  その場合は、タスクマネージャー等で「hook.exe」を停止するか、
  再度Anti-RebootKFMを選択した後、正常にMUGENを終了させてください。
